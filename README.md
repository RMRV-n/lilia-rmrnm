# Лилия · RMRNM

Нежная цветочная студия — авторский демонстрационный проект для портфолио **RMRNM**.

![Главная страница цветочной студии «лилия» — портфолио RMRNM](preview.jpg)

Главный образ — бело-розовая лилия. Фарфоровый фон, пудровые оттенки, ботаническая фотография, кириллическая типографика Cormorant Garamond и Manrope.

## Что работает

- Главная страница с лилией и выбором цветов.
- Каталог шести букетов: фильтры по цветам, бюджету, палитре и поводу, поиск и сортировка, снимаемые фильтры и пустые состояния.
- Шесть самостоятельных страниц букетов: состав, уход, три размера, обновление цены и выбранного варианта в корзине.
- Избранное и корзина с сохранением в браузере.
- Расчёт количества, стоимости доставки, бесплатной доставки от 7 000 ₽ и самовывоза.
- Демонстрация выбора даты и времени, открытки и итогов заказа.
- Страницы студии, доставки, ухода, информация о проекте и 404.
- Адаптивная вёрстка, клавиатурная навигация, модальные окна, reduced motion, локальные шрифты и оптимизированные WebP-фотографии.

**Это вымышленная студия.** Настоящие заказы и платежи не принимаются. Цены, размеры, наличие и условия доставки иллюстрируют интерфейс. Сайт не запрашивает контактные или платёжные данные, не отправляет открытки и не использует аналитику. Корзина и избранное сохраняются только в localStorage браузера.

## Запуск

Нужен Node.js 20 или новее, сторонние зависимости не нужны.

```sh
node build.mjs
node serve.mjs
```

Открыть http://127.0.0.1:4173 . Статические файлы находятся в `dist/`. Их также можно открыть локально через `dist/index.html`.

## Публикация

GitHub Pages: https://rmrv-n.github.io/lilia-rmrnm/

В репозитории выбрать **Settings → Pages → Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет JavaScript, формирует страницы и публикует `dist/` при обновлениях main. Дополнительный платный домен не требуется. Это адрес демонстрационного проекта для портфолио.

Все ссылки и ресурсы относительные, сайт поддерживает размещение в подпапке GitHub Pages.

## Редактирование

- `dist/assets/products.js` — товары, цены, составы и описания.
- `build.mjs` — разметка 13 страниц и общие компоненты.
- `dist/assets/style.css` — оформление и адаптивные размеры.
- `dist/assets/app.js` — фильтры, избранное, корзина, размеры, модальные окна.
- `notes/design.md` — концепция, палитра и изученные референсы.
- `notes/image-prompts.md` — промпты всех изображений, созданных встроенным imagegen.
- `prepare-fonts.mjs` — разовая загрузка локальных кириллических и латинских шрифтов; для запуска сайта повторять не требуется.
